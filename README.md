# Сервис заметок (notes-service)

**notes-service** — это простой веб-сервис для создания, хранения, редактирования и удаления текстовых заметок.

## 🛠️ Инструментальные средства
В ходе выполнения работы были использованы следующие инструменты:
* **Git** — локальная система контроля версий;
* **GitHub** — удаленный хостинг IT-проектов;
* **Командная строка Windows (cmd)** — для управления репозиторием;
* **GitHub Network** — для визуализации графа веток.

## 📂 Структура проекта
Проект содержит базовую текстовую архитектуру сервиса:
* `README.md` — описание проекта, структуры и процесса работы с Git;
* `project-notes.md` — общие заметки, требования и выбранный стек технологий;
* `api-plan.md` — структура планируемых эндпоинтов (маршрутов) API.

## 🔀 Описание Git workflow и конфликта
В репозитории зафиксировано более 6 осмысленных коммитов и продемонстрирована работа с ветками:
1. В ветке `main` были созданы стартовые файлы проекта и базовые описания.
2. Была создана ветка `feature-tags` для добавления функционала тегов, которая успешно влита в `main`.
3. Для демонстрации конфликта была создана ветка `feature-delete`. В ней и в ветке `main` была одновременно изменена одна и та же последняя строка файла `api-plan.md`:
   * В ветке `main` был добавлен метод `PUT /notes/:id` (Обновление заметки).
   * В ветке `feature-delete` был добавлен метод `DELETE /notes/:id` (Удаление заметки).

**Как исправлен конфликт:** При попытке выполнить `git merge feature-delete` система выдала предупреждение о конфликте. Файл `api-plan.md` был открыт вручную, маркеры конфликта (`<<<<<<<`, `=======`, `>>>>>>>`) удалены. В финальном файле были сохранены обе строки (так как для полноценного API требуются оба метода), после чего изменения зафиксированы специальным коммитом слияния.

## 📊 Граф веток (GitHub Network)

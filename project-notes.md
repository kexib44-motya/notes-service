# Заметки по проекту: Сервис заметок

## Основная идея проекта
Создание легковесного веб-приложения, которое позволяет пользователям быстро фиксировать свои мысли, создавать списки задач и хранить важную текстовую информацию в виде заметок.

## Функциональные требования (Фичи)
* **Авторизация:** Пользователи должны иметь возможность входить в свой аккаунт для синхронизации заметок.
* **Категории и теги:** Возможность группировать заметки по темам (например: "Работа", "Учеба", "Личное").
* **Поиск:** Быстрый полнотекстовый поиск по заголовкам и содержимому заметок.

## Планируемый стек технологий
* **Бэкенд:** Node.js (Express) или Python (FastAPI).
* **База данных:** PostgreSQL или MongoDB для хранения текстов заметок.
* **Фронтенд:** Чистый HTML/CSS/JavaScript для минималистичного интерфейса.

# План API для Сервиса заметок (notes-service)

В данном файле описаны основные маршруты (endpoints) для взаимодействия клиентской части приложения с бэкендом.

## Базовый URL
`/api/v1`

## Список маршрутов:

* **POST /notes** — Создать новую текстовую заметку.
* **GET /notes** — Получить список всех сохраненных заметок пользователя.
* **GET /notes/:id** — Получить детальную информацию по конкретной заметке по её ID.
* **PUT /notes/:id** — Обновить существующую заметку (изменить заголовок или текст).
* **DELETE /notes/:id** — Удалить заметку из системы.
